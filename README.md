# ✈️ Travel Recommendation Website

An interactive, responsive web application designed to help users discover curated travel destinations, explore local culture, and search for recommendations based on specific categories or keywords.

## 🌟 Key Features

- **Dynamic Destination Search:** Real-time JavaScript search logic to filter destinations by keyword, country, or category.
- **Rich Visual Cards:** Displays curated locations with high-quality media, localized descriptions, and recommended highlights.
- **Clean UI & Responsive Design:** Built with pure CSS for effortless navigation across desktop, tablet, and mobile displays.
- **Instant Result Reset:** Clear functionality to easily reset search parameters and return to full list views.

---

## 🛠️ Built With

- **HTML5:** Semantic structural layout and markup.
- **CSS3:** Custom page layouts, card components, and visual styling.
- **Vanilla JavaScript (ES6+):** DOM manipulation, array filtering logic, and interactive event handling.
